# Ruhroh Law Firm Website

A modern, responsive website for a fictional law firm, designed to be hosted on GitHub Pages.

## Description

This project is a clean, professional website for a law firm that showcases their services, attorneys, and provides a way for potential clients to get in touch. The design is modern, responsive, and focused on creating a trustworthy and authoritative online presence.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices from mobile phones to large desktop screens
- **Modern Aesthetics**: Clean, professional design with a color scheme appropriate for a law firm
- **Interactive Elements**: 
  - Testimonial slider
  - Mobile-friendly navigation
  - Form validation
  - Smooth scrolling
  - Hover effects
- **Sections Include**:
  - Hero banner with call-to-action
  - About the firm
  - Practice areas
  - Attorney profiles
  - Client testimonials
  - Contact form
  - Footer with social links and site map

## Technologies Used

- HTML5
- CSS3 (with CSS variables for theming)
- JavaScript (vanilla, no frameworks)
- Font Awesome for icons
- Google Fonts (Playfair Display and Raleway)

## Setup and Usage

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/ruhroh.github.io.git
   ```

2. Navigate to the project directory:
   ```
   cd ruhroh.github.io
   ```

3. Open `index.html` in your browser to view the website locally.

4. To deploy to GitHub Pages:
   - Push the code to your GitHub repository
   - Go to repository settings
   - Under "GitHub Pages" section, select the main branch as the source
   - Your site will be published at `https://yourusername.github.io/ruhroh.github.io/`

## Image Placeholders

This project uses HTML placeholders for images. In a production environment, these would be replaced with actual image files. The placeholders are located in the `images` directory with `.html` extensions:

- `hero.jpg.html` - Hero section background
- `office.jpg.html` - Office image for the About section
- `attorney1.jpg.html`, `attorney2.jpg.html`, `attorney3.jpg.html` - Attorney profile images

To replace with real images:
1. Add your image files to the `images` directory
2. Update the references in `index.html` to point to your image files instead of the HTML placeholders
